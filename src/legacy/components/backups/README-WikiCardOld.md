# Backup visual antigo - Wiki Interna

Este diretório preserva o card Wiki anterior à alteração visual solicitada.

- `WikiCardOld.jsx`: JSX antigo completo.
- `WikiCardOld.css`: CSS antigo completo, incluindo responsividade.

O componente não é importado pela página atual. Para restaurar, substitua o
componente novo por `WikiCardOld` no primeiro item de `InfoCards`.
